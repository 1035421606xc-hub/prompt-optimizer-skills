# Prompt Optimizer Skills

这是一个面向聊天产品的提示词优化 skill 合集。它把零散想法、口述内容、半成品问题或旧提示词，整理成可以直接发送给对应模型的完整提示词。

## 50：Claude Opus 5 提示词优化器

50 面向 Claude Opus 5。它会补齐真实目标、背景、范围、证据、权限、成功标准与交付形式，同时删除旧模型时代常见的重复验证、强制逐步思考和不必要的多代理指令。

## 56：GPT-5.6 Sol 提示词优化器

56 面向 GPT-5.6 Sol。它把模糊需求整理成一份任务合同，让模型先抓住你真正想完成的事情，再自行选择有效执行路径。

## 如何下载

不熟悉 GitHub 时，可以点击仓库页面右上方的 Code，再选择 Download ZIP。也可以直接使用本仓库的 ZIP 下载链接。

下载并解压后，把完整的 `50` 和 `56` 文件夹复制到你的 skills 目录。不要只复制 `SKILL.md`，因为 50 还包含模型参考文件，两个 skill 也各自包含代理配置。

## 如何使用

安装后，在支持 skill 的聊天或代理产品中输入 `$50` 或 `$56`，后面直接接上你的原始想法。

```text
$50 我想深入学习游戏产业，但是不知道该怎么开始
```

```text
$56 帮我把这个模糊的研究想法整理成一条可以直接使用的提示词
```

50 与 56 的价值不是把提示词机械拉长，而是识别目的、补齐关键条件，并删除不会改变结果的废话。

## 适用边界

这两个 skill 生成提示词，不直接执行提示词背后的任务。50 针对 Claude 聊天产品，56 针对使用 GPT-5.6 Sol 的聊天应用。
